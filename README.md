## 🇸🇦 اللغة العربية

تطبيق ويب خفيف وتفاعلي وبسيط يتيح للمستخدمين بناء وعرض وتنسيق شجرة العائلة بسهولة تامة. يعمل التطبيق بالكامل داخل المتصفح وبدون الحاجة لإنشاء حساب أو وجود خادم خلفي (Backend).

### ✨ المميزات الرئيسية
* **بناء الشجرة وسلسلة النسب:** إضافة الآباء والأبناء مع تمييز الذكور والإناث بأشكال وألوان متناسقة.
* **ترتيب الأبناء:** إمكانية تحريك أي ابن أو ابنة يميناً ويساراً لترتيب الأبناء حسب السن أو الرغبة، مع نقل جميع أحفادهم وفروعهم تلقائياً.
* **متوافق مع الجوال والآيفون:** دعم كامل للتمس والتكبير والتصغير (Pinch to zoom) وسحب الشاشة.
* **حفظ الشجرة كصورة (PNG):** تصدير الشجرة كصورة عالية الجودة بضغط زر، مع دعم خاص لنظام iOS (قائمة المشاركة الرسمية والمعاينة).
* **نسخ احتياطي للبيانات:** إمكانية **تصدير** بيانات الشجرة بصيغة `JSON` و**استيرادها** في أي وقت.
* **حفظ تلقائي:** يتم حفظ جميع التعديلات محلياً في ذاكرة المتصفح (`LocalStorage`).

### 🛠️ التقنيات المستخدمة
* **HTML5 & CSS3:** لتصميم الواجهة والبطاقات والخطوط.
* **JavaScript (Vanilla JS):** لبناء منطق الشجرة والتحكم بالبيانات دون مكتبات ثقيلة.
* **html2canvas:** لتحويل الشجرة إلى صورة PNG.

### 🚀 طريقة التشغيل
1. قم بفتح ملف `index.html` مباشرة عبر أي متصفح.
2. أو ارفعه على **GitHub Pages** ليعمل كموقع إلكتروني أونلاين.

## 🇬🇧 English

A lightweight, interactive, and responsive web application that allows users to build, display, and organize their family trees with ease. It runs entirely inside the browser without requiring user registration or a backend server.

### ✨ Key Features
* **Tree & Lineage Building:** Add parents, sons, and daughters with distinct shapes and colors for male and female members.
* **Sibling Reordering:** Reorder children left or right easily by age or preference. Sub-branches and descendants move automatically without breaking tree lines.
* **Mobile & iOS Friendly:** Full touch support including pinch-to-zoom and canvas panning.
* **Export as Image (PNG):** Download the family tree as a high-resolution PNG image with built-in iOS Share Sheet support.
* **Data Backup:** Easily **Export** tree data to a `JSON` file and **Import** it anytime.
* **Auto-Save:** All changes are stored locally in the browser's `LocalStorage`.

### 🛠️ Tech Stack
* **HTML5 & CSS3:** For interface layout, tree connections, and custom fonts.
* **JavaScript (Vanilla JS):** Core logic for rendering and managing tree structures.
* **html2canvas:** For capturing the canvas and generating PNG images.

### 🚀 How to Run
1. Open `index.html` directly in any modern web browser.
2. Or host it for free using **GitHub Pages**.

---

### 🔒 Privacy / الخصوصية
All data is saved locally on the user's device. No personal names or tree data are sent to any external server.
